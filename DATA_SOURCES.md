# Data and method sources

[PhysioNet EEGMMIDB 1.0.0](https://physionet.org/content/eegmmidb/1.0.0/), Schalk (2009), DOI [10.13026/C28G6P](https://doi.org/10.13026/C28G6P). Open Data Commons Attribution v1.0; official EDF checksums were verified.

[MNE motor-imagery CSP example](https://mne.tools/stable/auto_examples/decoding/decoding_csp_eeg.html) provides the conventional spatial-filtering reference.

Only aggregate evaluation summaries and original presentation figures are included here. No raw datasets, trained weights or third-party source code are redistributed. Underlying data/software retain their own terms.
